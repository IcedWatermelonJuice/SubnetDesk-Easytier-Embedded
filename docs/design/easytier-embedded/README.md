# SubnetDesk EasyTier 控制台集成方案

基线为 SubnetDesk `v2.0.0`（`b4dfa874ecb7`），施工分支为 `easytier-embedded`。已实施；首页开关、来源限制及密码保存的后续约定见 [访问控制与界面增补](access-controls.md)。

## 入口与分工

| 位置 | 新增内容 | 行为 |
| --- | --- | --- |
| 组网页 | EasyTier 控制台 | 管理多个 TOML 方案、选择当前方案、启动和停止实例、查看当前节点与路由 |
| 首页右上角 | 「快速启动 EasyTier」「仅允许 EasyTier 远控」 | 启动上次选择的方案；开启来源限制会启动组网，主动关闭组网会同时关闭来源限制 |
| 首页底部 | 「附近的设备」「EasyTier 设备」「收藏」 | 切换预览来源；EasyTier 与设备页共用节点数据及刷新 |
| 设备页 | 「EasyTier」分类 | 使用组网页的同一份运行中节点数据，显示名称和虚拟 IP |
| EasyTier 设备行 | 「填入 IP」 | 填入现有远程地址框并切到远程页，等待用户自行点击连接 |

例如，点击节点 `10.88.0.7` 行的「填入 IP」，远程地址框显示 `10.88.0.7`。用户可以编辑地址或补端口。此动作不会发起连接，也不产生最近连接记录。纯 EasyTier 节点和运行 SubnetDesk 的节点使用相同操作，无需探测对端软件。

## 组网页

### 多方案管理

每个方案对应一份实际的 EasyTier TOML 和一个应用内显示名称。使用稳定的方案 ID 保存当前选择，重命名后仍指向同一份配置。

| 操作 | 行为 |
| --- | --- |
| 新建、复制、重命名、删除 | 管理独立方案。复制后可单独修改，删除运行中的方案需先停止 |
| 编辑 | 表单覆盖网络名称、密钥、引导节点、DHCP 和固定虚拟 IP 等常用配置。提供 TOML 编辑入口使用其他配置项 |
| 导入 `config.toml` | 读取并校验后保存为独立方案。重名时可改名，不默认覆盖。格式或配置不兼容时显示原因 |
| 导出 `config.toml` | 输出所选方案的标准 EasyTier TOML，可供原版 EasyTier 使用。包含密钥时，在导出前提示文件含凭据 |
| 选择方案 | 保存为当前选择，也是远程页快速启动的目标。选择或保存方案不会自动启动或者中断当前实例 |

导入的 TOML 保留有效字段，包括表单没有覆盖的上游配置项。通过表单修改时只更新对应字段。保存时校验语法和固定版本可识别的配置，运行失败另外显示。管理 RPC 的回环绑定由应用启动参数固定，不依赖导入配置。密钥及 TOML 内容不写入日志，不通过命令行传入。内部配置与凭据存储按本机用户权限限制。EasyTier v2.6.4 支持独立的配置解析命令，可以在导入和保存时复用。[上游配置校验](https://github.com/EasyTier/EasyTier/blob/v2.6.4/easytier/src/core.rs#L1492-L1533)

### 启动、停止与切换

同一时间只运行一个受管实例，可以保存多个方案。页面分别显示选中的方案和当前运行的方案，避免切换下拉框后误以为已换网。

- **启动**使用当前选中的已保存配置。方案尚未保存时提示保存。启动中或相同方案已运行时避免重复启动。
- **停止**只影响 SubnetDesk 启动的 EasyTier 实例。停止或实例退出后清除当前节点和路由。
- **切换运行方案**时，明确展示从哪个方案切到哪个方案。启动另一个方案会先停止现有实例，再加载目标方案。如果新方案启动失败，显示失败及重试入口。
- 修改运行中方案时标记配置已更改，用户可选择重启以应用新配置。
- 显示启动中、运行中、已停止及失败，以及运行方案、本机虚拟 IP、最近错误。启动权限不足或组件缺失时明确提示。

远程页复用同一个启动操作。首次导入或创建方案后自动选中该方案。没有有效选择时打开组网页，等待用户选择或新建。上次选中的方案仍有效时直接启动它，无需另维护一份快捷配置。

### 当前节点与路由

这里的“当前局域网”指正在运行的 EasyTier 虚拟局域网。组网页分设「节点」和「路由」两个视图。设备页的 EasyTier 分类复用节点视图的数据。

| 视图 | 展示内容 |
| --- | --- |
| 节点 | 节点名称、虚拟 IP。按引擎实际返回的信息显示连接协议、延迟或经中继等状态 |
| 路由 | 目标虚拟 IP 或子网、下一跳、路径跳数和延迟。以 EasyTier 报告的路由为准 |
| 运行状态 | 已选方案、实际运行方案、本机虚拟 IP、查询时间及错误 |

节点和路由在页面可见时刷新，并提供手动刷新。未启动、启动中、当前没有节点以及查询失败显示不同状态。切换方案后丢弃旧实例返回的查询结果。没有可填地址的节点仍可显示，按钮不可用并说明原因。

## 实现方式

主应用管理一个常驻 `easytier-core` 子进程。首期建议使用已经离线核对的官方 `v2.6.4` core 和 CLI，按发行平台锁定版本与校验值。启动时显式将管理地址绑定到本机回环，CLI 按需读取 `peer list` 和 `route list` 的 JSON。若目标平台必须对本机调用者做额外访问控制，改用核心的受控本地接口。两种查询方式只选一种。[CLI 命令分派](https://github.com/EasyTier/EasyTier/blob/v2.6.4/easytier/src/easytier-cli.rs#L2684-L2743) · [路由字段](https://github.com/EasyTier/EasyTier/blob/v2.6.4/easytier/src/easytier-cli.rs#L1589-L1607) · [管理地址解析](https://github.com/EasyTier/EasyTier/blob/v2.6.4/easytier/src/rpc_service/api.rs#L164-L198)

Rust 不解析终端表格。引擎适配层提供方案列表、当前选择、运行状态、节点快照和路由快照。进程与查询在后台执行，应用退出时只收尾自己启动的实例。Flutter 的组网页、远程页快捷按钮和设备分类共用这套数据及操作。

新建方案继续采用已讨论的默认原则。多线程、延迟优先、私有模式和 DHCP 作为候选默认，QUIC 按引擎支持的隧道传输配置启用。物理网卡广播中继、QUIC TCP 流代理以及修改系统 DNS 的 Magic DNS 保持默认关闭。导入方案的选项与新建默认分开处理，页面呈现所选方案的有效配置。

远控认证和监听策略不变。来源限制由首页独立开关控制；单独启动 EasyTier 不改变本机原有远控开关，组网仍可独立使用。

## 施工顺序

1. **方案与引擎适配**。实现多份 TOML 保存、导入导出、选择持久化、子进程切换、状态及节点和路由查询。
2. **组网页与快速启动**。实现控制台界面，让远程页调用同一组网启动操作，并显示当前选择。
3. **设备分类与地址回填**。复用节点数据，将有效虚拟 IP 送入现有远程输入框。
4. **打包**。优先交付 Windows，随包检查匹配的引擎和 CLI 资源。其他桌面平台复用界面和后端接口。

第 1 项与第 2、3 项可基于同一提交在独立 `feat/*` worktree 并行。先对齐方案 ID、选择与运行状态、节点和路由字段。界面任务统一拥有远程输入框和设备分类接点。常规界面与文案任务可交给 `luna`。

## 必要验收

- 至少两份 TOML 可独立编辑并切换。导入后再导出的配置能由固定版本 EasyTier 读取，未编辑的有效字段保留。
- 组网页可启动、停止和切换实例。重启应用后，远程页快速启动使用上次选择的方案。
- 当前 EasyTier 网络的节点与路由和同一实例的查询结果一致。切换网络后不显示旧实例数据。
- 设备行按钮只填入虚拟 IP，包括未安装 SubnetDesk 的节点。手动点击连接后才进入现有远控流程。
- EasyTier 停止时，现有 LAN 功能照常工作。

先审核方案，功能实现和运行验证留待后续。
