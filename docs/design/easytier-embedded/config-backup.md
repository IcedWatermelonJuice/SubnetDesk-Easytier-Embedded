# 应用配置备份与恢复

## 入口与范围

设置 → 通用 → 配置备份与恢复。导出文件扩展名为 `.sdbak`，采用用户输入的备份密码加密；恢复需要同一个密码。

备份覆盖配置目录中的应用配置、设备身份、LAN 配置、收藏与分组，以及 EasyTier 全部方案和选择状态。另行处理系统凭据库中的 LAN 密码回显、登录身份密码和按设备记住的 LAN 密码，不能只复制 TOML 后宣称备份完整。

不备份日志、录屏、发现缓存、运行状态及系统自启动任务。恢复不创建或修改系统自启动任务，也不应删除当前目标已有的自启动配置。

当前格式支持原电脑恢复。现有部分凭据使用机器绑定密钥加密，不承诺跨电脑完整迁移；禁止静默接受无法恢复的机器绑定凭据。

## 文件与操作约束

- 使用已有 Sodium Argon2id 密钥派生及 secretbox 认证加密，不自行设计密码算法，不添加新依赖。
- 密码不写入日志、常规配置或状态返回值。临时恢复内容也必须加密，其随机密钥保存在本机系统凭据库。
- 导出使用原子写入，不能覆盖配置源或已有备份文件。
- 校验版本、容量、路径范围、重复文件以及 EasyTier 索引和 TOML；拒绝路径穿越、符号链接及越界写入。
- 文件读写由后台处理，界面根据请求 ID 匹配结果。等待超时不代表成功，也不能把其他请求的完成当成本次完成。

## 恢复生命周期

1. 选择备份、输入密码并确认覆盖。
2. 在当前进程中完成解密与校验，只暂存恢复内容，不修改当前运行配置。
3. 完整退出应用，下次启动时由主进程取得单实例锁，在任何配置缓存初始化之前执行恢复；连接管理器和远控等子进程不能执行恢复。
4. 替换前保留原配置副本，EasyTier 方案与系统凭据失败时回滚。保留足够的恢复记录，不能在崩溃后把自动新建的空目录误判为恢复成功。
5. 成功和失败结果在设置页面可见；失败必须显示错误，不能静默成功。

## 必要验证

验证认证加密往返、错误密码和损坏文件拒绝、路径和重复项拒绝、恢复失败回滚。测试只使用隔离临时目录和模拟凭据，不修改用户现有配置或系统凭据。最后执行现有 Windows Release 构建。
