# 访问控制与界面增补

本文件记录 2026-11-21 用户确认的后续行为，优先于初版方案中“仅添加控制面”的范围描述。

## 首页开关

右上角与「可被发现」「可被远程」并列，使用同一套开关卡片样式。

| 操作 | 结果 |
| --- | --- |
| 开启快速启动 | 启动上次选择的 EasyTier 方案；没有方案时进入组网页 |
| 开启仅允许 EasyTier 远控 | 如未组网则启动上次选择的方案，并启用来源 IP 限制 |
| 主动关闭快速启动，或在组网页点击停止 | 停止受管实例，并关闭来源限制 |
| 单独关闭来源限制 | 保留 EasyTier 实例，恢复原有 LAN/VPN 来源策略 |
| 引擎异常退出或查询失败 | 保持来源限制，拒绝新的入站连接；不自动放行 LAN |
| 应用重启且上次来源限制开启 | 保持限制并启动上次选择的方案；启动失败仍拒绝新连接 |

该开关不代替「可被远程」，不自动开启远控接收，也不绕过用户名、密码、设备身份和权限检查。

## RC9 方案选项与代理兼容

- 方案编辑器提供“延迟优先”开关，对应 `[flags].latency_first`；新建方案默认开启，已有及导入方案按实际值回显，保存后重启当前组网应用。
- Windows 和 Android 在保存及启动方案时统一强制 `disable_quic_input = true`、`disable_kcp_input = true`、`enable_quic_proxy = false`、`enable_kcp_proxy = false`，不以是否勾选“仅允许 EasyTier 远控”为条件。旧存储方案在启动时同样覆盖，无需重新导入。
- 原因：QUIC／KCP TCP 加速代理会在被控端重建 TCP 连接，远控入口可能只看到被控端自身 IP，无法使用现有来源白名单识别原始节点。保留普通 QUIC 隧道，不把本机地址或整个虚拟网段加入允许来源。
- Android 另保持 `proxy_forward_by_system = false`、`no_tun = false`、`enable_udp_broadcast_relay = false`；运行时 `bind_device = false`。`accept_dns = true` 仍明确拒绝。
## 来源 IP 检查

- 在现有远控监听入口复用来源检查；启用时只允许受管 EasyTier 实例返回的节点虚拟 IPv4。
- 同时约束原生远控、复用该来源检查的发现应答，以及 Web 入口；不能通过 Web 自定义白名单绕过。
- 不把节点发布的代理子网当作允许来源；IPv4-mapped IPv6 按 IPv4 处理。
- 开启限制时后台每 5 秒查询一次，不依赖用户停留在组网页。失败立即清空快照，超过 15 秒的快照拒绝新连接。
- 停止、切换方案和异常退出都会清空旧节点。关闭限制后沿用已有的手工 CIDR 配置，不删除该配置。
- 保存 LAN 设置应合并现有选项，不能覆盖掉来源限制开关或其他选项。来源限制开启时，LAN 设置的「网络」输入框禁用，显示「被 EasyTier 接管」；保留原手工 CIDR，关闭限制后恢复编辑。
- 只按来源 IP 匹配，不识别入站网卡，不配置 WFP 或系统防火墙，不主动断开已有会话。

## 首页节点预览

首页底部为「附近的设备／EasyTier 设备／收藏」。EasyTier 未运行时列表为空，运行后展示实际节点。

首页、设备页的 EasyTier 分类及组网页共用同一个 `EasyTierController` 和节点快照；任一入口刷新都会更新同一份数据。没有有效 IP 的节点不显示。首页将节点转换为 `WorkspaceDevice` 并复用普通设备卡片，在有高度约束的独立滚动区显示全部节点；标题固定，不得通过 `FittedBox` 随节点数量缩小文字。设备页复用其他分类的搜索、分页和表格组件。两处操作区使用连接图标，仍只填入 IP，不自动发起连接、不探测对端是否安装 SubnetDesk；不能把普通设备的更多菜单或直接连接动作套到 EasyTier 节点。未执行 SubnetDesk 可达性探测时仍显示「未检查」。

## 配置和密码

- EasyTier 运行时的 `hostname` 统一取「本机」中的设备名称，覆盖导入方案中的同名字段，但不修改原始方案文件；改名后提示运行配置已更改，重新启动所选方案时应用新名称。
- 方案选择使用带选中标记的圆角菜单，限制菜单高度并允许滚动，长名称省略显示。选中项使用已适配的 `surfaceContainerHighest` 底色与 `onSurface` 文字／图标色，避免使用尚未适配的 `secondaryContainer` 导致黑底。
- EasyTier 方案编辑采用 LAN 设置的标题图标、浅色填充输入框、圆角边框、开关卡片与底部按钮样式，同时支持深色主题。
- 网络密钥默认隐藏，可以显示／隐藏；切换显示状态不视为修改密钥。
- LAN 认证继续使用密码哈希；额外通过现有 `keyring` 库保存在操作系统凭据存储中，不向 TOML、Config 选项或日志写入明文密码。
- 凭据按配置文件路径隔离。读取时校验当前用户名和实际密码哈希，拒绝回显过期凭据。
- 本机界面通过独立的本地读取键取回密码，不向常规状态 JSON 或 Web 接口返回明文。
- 重新打开默认遮蔽已保存密码；未修改用户名和密码时保存不重新生成认证版本。保存系统凭据失败时不修改认证密码，后续认证写入失败时尝试回滚系统凭据。

## 设备列表清理

- 附近设备和最近连接均自动清理：最近一次发现已超过 30 分钟，且当前发现结果明确为不可达时移除；未检查或发现证据过期不作为不可达依据。
- 只有最近连接提供「从最近连接移除」菜单。移除状态持久保存，旧的在线缓存不能让设备立即恢复；再次刷新发现在线或重新成功连接后恢复。
- 清理列表不删除收藏、分组、设备身份和认证凭据。自动清理附近缓存之前先保存最近连接的移除状态，保存失败时保留缓存并记录错误。
- EasyTier 设备始终使用 core 的实时节点快照，不对该列表套用局域网发现缓存的半小时清理规则。

## 必要验收

来源策略的定向测试覆盖：已知 IP、未知 IP、普通 LAN 来源、IPv4-mapped IPv6、缺失数据、空节点和过期快照。执行实际使用的源码模块测试即可，无需为该策略启动虚拟网卡。

构建验证使用现有 Windows Release 流程；密码回显和实际远控／组网留作交互实测，不修改用户现有凭据来做自动化测试。

## 会话管理与工具栏

- 入站连接恢复可见的 CM 管理窗口，不继承隐藏设置、不在连接后自动最小化；远控会话显示红色提示，提供单会话断开和多会话全部断开。窄窗口的操作区可独立滚动。
- 远控画面状态变化保留同一个聊天 Overlay，避免反复重建使聊天窗口消失。
- 录屏先设置录制状态，再请求关键帧；启动时检查保存目录，写帧错误停止录制并显示错误，状态提示包含保存目录。
- Windows 交互宿主的隐私屏使用本进程黑色窗口，必须先成功排除屏幕采集再允许显示；复用现有输入限制、显示器覆盖检查和断线恢复。不再依赖注入 DLL。该路径要求 Windows 10 2004 或更新版本。
- Windows 管理员宿主启动普通远程终端时，获取同一用户、同一会话且确认未提升的 UAC linked token；不让普通终端直接继承管理员权限。无有效非提升令牌时明确失败。helper 管道保留仅 SYSTEM 和目标用户的访问控制，允许普通用户完整性级别通信。
- 编译和静态检查不等于交互实测：聊天双向收发、录屏文件播放、隐私屏本机遮挡/远端画面/断线恢复和终端命令执行应在两台测试设备上确认。
