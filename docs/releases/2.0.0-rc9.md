# 2.0.0-rc9 · build 78

本次提供 Windows x64 便携 ZIP 和 Android arm64-v8a 测试 APK，作为预发布版本供验证。

## 本次更新

- 两端方案编辑器新增“延迟优先”开关（`latency_first`），按已有配置回显，保存后重启当前组网生效。
- 两端保存及启动时强制关闭 QUIC／KCP TCP 加速代理收发，修复该代理重建本地 TCP 连接后被“仅允许 EasyTier 远控”拒绝的问题。普通 QUIC 隧道保留，未放宽来源白名单。
- Android 兼容桌面导入方案：`proxy_forward_by_system`、`no_tun`、`enable_udp_broadcast_relay` 强制关闭；运行时保持 `bind_device = false`。
- 手机远控工具栏新增 0°／90°／180°／270° 本地画面旋转，同步处理光标和输入坐标；窄屏工具栏可横向滚动。
- 整合 Android VPN 服务、原生 EasyTier 核心、状态同步与生命周期处理，并保持仅 EasyTier 的来源限制。
- 重写本仓库的中英文 README，补齐临时文件、缓存、运行数据、安装包及签名凭据的 Git 忽略规则。

## 安装与验证

- Windows：完整解压 ZIP，启动顶层 `SubnetDesk.exe`；升级前退出旧版，保留 `userdata/`。Windows 包未签名。
- Android：Android 7.0／API 24 及以上，arm64-v8a；测试签名与前一版一致，可覆盖安装。versionName 为 `2.0.0-rc9`，实际 arm64 分包 versionCode 为 `2078`。
- 新安装包包含配置覆盖修复，但已运行的旧组网实例需要重启后才会应用。
- 定向测试、完整 Release 构建、ZIP／APK 完整性与版本检查通过。Android 原生库依赖及 16 KiB 对齐检查通过；尚未完成真机远控／VPN 验收。
- 不包含其他操作系统或 CPU 架构的 RC9 安装包。下载后可使用随附 `SHA256SUMS` 核对摘要。
