# SubnetDesk-Easytier-embedded v2.0.0-rc10 · build 79

本次提供 Windows x64 便携 ZIP 和 Android arm64-v8a 测试 APK。

## 本次更新

- 修复 Windows 远程终端无法打开、提示无法取得非管理员令牌的问题。交互宿主直接通过 ConPTY 创建 Shell，终端继承 SubnetDesk 的账户与权限：管理员宿主对应管理员终端，不再强制降权。
- Windows 隐私模式改为深色提示画面，显示“此电脑正在被远程控制”和恢复说明。每块显示器分别居中、适配缩放，继续使用现有采集排除、输入限制和断线恢复机制。
- 修复手机和 Windows 的 EasyTier 方案编辑器中“延迟优先”开关缺少底框的问题，补齐圆角背景、边框及深色主题样式。
- 更新中英文 README，统一两端版本为 `2.0.0-rc10`、build `79`。

## 安装与验证

- Windows：完整解压 ZIP，启动顶层 `SubnetDesk.exe`；升级前从托盘退出旧版，替换程序文件并保留 `userdata/`。Windows 包未签名。
- Windows 新隐私提示用于现有 Windows 10 2004 或更新版本的交互宿主隐私屏路径，不改变旧系统的隐私模式实现。
- Android：Android 7.0／API 24 及以上，arm64-v8a；沿用前版测试证书，可覆盖安装。versionName 为 `2.0.0-rc10`，实际 arm64 分包 versionCode 为 `2079`。
- 发布前检查两端 Release 构建、现有定向 UI 测试、安装包版本及完整性；Android 检查签名连续性、原生库依赖和 16 KiB 对齐。
- 尚未完成双机远控／真机 VPN 验收；隐私屏远端采集排除、多屏混合缩放和断线恢复仍需实机确认。离屏绘制预览不能替代这些检查。
- 本次不包含其他操作系统或 CPU 架构安装包。下载后可使用附件 `SHA256SUMS` 核对摘要；`rc10-build-manifest.json` 记录共同源码提交和两端构建信息。
